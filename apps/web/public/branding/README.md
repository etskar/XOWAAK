# Official XOWAAK Branding Assets

No official logo, icon, favicon, or font files are present in this workspace yet.

When supplied, add only verified source assets here using clear names such as:

- `xowaak-logo.svg` for the approved full logo
- `xowaak-icon.svg` for the approved standalone icon
- `xowaak-icon-dark.png` and `xowaak-icon-light.png` for supplied raster variants
- `xowaak-favicon.svg` only when supplied or technically derived from the approved icon

The supplied assets are the only source of truth. Do not redraw, replace, recolor, resize
non-proportionally, mirror in RTL, or recreate the XOWAAK mark with CSS or generated artwork.

Document the intended usage and provenance of every future variant before adding it.
